Automation Integration

Connect Notch Touch with Tasker, MacroDroid, or any Android automation engine via broadcast intents.

Trigger Automation Tasks

Execute routines in Tasker or MacroDroid instantly whenever a notch gesture is performed.

Scenario: Smart Home Lockdown

Double-tap your camera cutout to run an automation task that turns off your smart desk lights, silences ringer volume, and locks your device.

Configuration Guide
1. In Tasker: Navigate to Preferences > Misc and enable Allow External Access. 2. Create your desired Task and give it an exact name (e.g., BedtimeRoutine). 3. In Notch Touch: Assign a gesture to ❖ RUN TASKER and enter the exact Task name (BedtimeRoutine).
1. In MacroDroid: Add a Macro and select Triggers > Device Events > Intent Received. 2. Configure the Intent trigger as follows:
Action:net.dinglisch.android.tasker.ACTION_TASK
Extra 1 Name:task_name
Extra 1 Value:BedtimeRoutine
3. In Notch Touch: Set the gesture action to ❖ RUN TASKER and enter BedtimeRoutine.

Dynamic Gesture Remapping

Reprogram assigned notch actions dynamically based on time, battery, Wi-Fi status, or foreground app.

Scenario: Night Mode Remapping

Switch your Double-Tap action from Camera during the day to Flashlight automatically at 9:00 PM.

Broadcast Intent Specification
// Add Action > System > Send Intent
Action:com.chaos.notchtouch.SET_GESTURE_ACTION
Extra 1:gesture_key:double
Extra 2:action_name:ACTION_TOGGLE_FLASHLIGHT
Target:Broadcast Receiver
// Add Action > Connectivity > Send Intent
Target:Broadcast Receiver
Action:com.chaos.notchtouch.SET_GESTURE_ACTION
Extra 1:Name: gesture_key | Value: double (String)
Extra 2:Name: action_name | Value: ACTION_TOGGLE_FLASHLIGHT (String)
Valid gesture_key values: single, double, triple, hold, left, right, left_hold, right_hold

Gesture State Control (Killswitch)

Selectively pause or resume individual gestures during specific contexts without stopping the background service.

Scenario: E-Reader / Fullscreen Gaming

Disable single-tap and hold gestures automatically whenever Kindle or a game runs in the foreground to eliminate accidental touches.

Broadcast Intent Specification
// Send Intent via Tasker or MacroDroid
Action:com.chaos.notchtouch.SET_GESTURE_STATE
Extra 1:gesture_key:single
Extra 2:is_disabled:true
Target:Broadcast Receiver
Set is_disabled to true (boolean or string) to block touches, or false to restore standard operation.
