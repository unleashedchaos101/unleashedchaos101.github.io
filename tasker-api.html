Notch-Touch x Tasker

Official API Documentation for Inter-Process Communication (IPC)

From Notch-Touch to Tasker

Trigger a complex Tasker sequence simply by tapping your camera cutout.

1. In Tasker: Preferences > Misc > Enable 'Allow External Access' 2. In Tasker: Create a named Task (e.g., 'TurnOffLights') 3. In Notch-Touch: Select '❖ RUN TASKER' and enter the exact Task Name.

From Tasker to Notch-Touch (Kill-Switch)

Dynamically disable or enable specific notch gestures. Perfect for gaming or fullscreen media.

In Tasker, create a 'Send Intent' Action:
Action:com.chaos.notchtouch.SET_GESTURE_STATE
Extra 1:gesture_key:single
Extra 2:is_disabled:true
Target:Broadcast Receiver

Keys: single, double, triple, left, right, left_hold, right_hold, hold is_disabled: Use 'true' to block the touch, 'false' to re-enable.

From Tasker to Notch-Touch (Remapping)

Instantly overwrite a gesture's action without opening the Notch-Touch app.

In Tasker, create a 'Send Intent' Action:
Action:com.chaos.notchtouch.SET_GESTURE_ACTION
Extra 1:gesture_key:double
Extra 2:action_name:ACTION_OPEN_CAMERA
Target:Broadcast Receiver

Ensure 'action_name' strictly matches the internal enum.
